# 2. Project structure

Where things are, and where to add yours.

## Layout

A uv workspace with two packages that share one version and one git tag.

```text
pyproject.toml          workspace root: shared dev/docs tools, ruff, pytest, semantic-release, commitizen
backend/                package genai-template-backend (FastAPI)
  pyproject.toml        backend dependencies (optional cpu / cuda PyTorch extras)
  src/genai_template_backend/
    app.py              FastAPI application
    api/llm.py          LLM client (LiteLLM)
    api/routes/chat.py  chat routes
    backend_settings.py settings (pydantic-settings, .env) and the loguru logger
frontend/               package genai-template-frontend (NiceGUI)
  src/genai_template_frontend/
    main.py             NiceGUI application
    components/chat.py  chat component
    frontend_settings.py
tests/unit/             self-contained backend, frontend and tooling tests
tests/integration/      real LLM, Ollama and API-to-model tests
tests/hardware/         explicit CUDA checks
scripts/                commit parser, release artifact checks and workspace docs generators
makefiles/              one .mk per concern, included by Makefile
docs/developer/         these pages
docker-compose.yml      application services and model provisioning
docker-compose-cuda.yml GPU override for Ollama
Dockerfile              backend and frontend image targets
.github/                workflows, composite actions, Renovate, issue and PR templates
```

## Add a backend route

1. Add the route in `backend/src/genai_template_backend/api/routes/` (an `APIRouter`).
2. Include the router in `app.py`.
3. Add isolated API tests in `tests/unit/backend/` and live-service tests in `tests/integration/`.
   The route appears in `/docs` automatically.

## Add a setting

1. Add a field to the `ApplicationSettings` class in `backend_settings.py` (or
   `frontend_settings.py`). A secret is a `SecretStr`.
2. Add it, with a safe example value, to `.env.example`.
3. Read it through the module-level `settings` object.

## Add a dependency

`uv add --package genai-template-backend <pkg>` (or `--package genai-template-frontend`), then
commit `uv.lock`.
