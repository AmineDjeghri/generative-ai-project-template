# 6. Fork

Create your repository with GitHub's "Use this template", then rename.

## Rename

| What                  | Where                                                                                                              |
|-----------------------|--------------------------------------------------------------------------------------------------------------------|
| workspace name        | `pyproject.toml`: `[project] name`                                                                                 |
| backend package       | `backend/pyproject.toml` `name`, folder `backend/src/genai_template_backend/`, imports in `tests/` and `frontend/` |
| frontend package      | `frontend/pyproject.toml` `name`, folder `frontend/src/genai_template_frontend/`, imports in `tests/`              |
| logger name           | `bind(name=...)` and its `filter` in both packages' settings modules                                               |
| run targets           | `makefiles/run.mk` (paths to `app.py` and `main.py`)                                                               |
| containers            | `Dockerfile*`, `docker-compose*.yml`                                                                               |
| documentation         | `README.md`, `AGENTS.md` (`CLAUDE.md` links to it), `properdocs.yml` (`site_name`), `SECURITY.md`, `docs/`         |
| version and changelog | semantic-release owns `project.version` and `CHANGELOG.md`; never edit them by hand                                |

Then: `uv lock`, `make install-dev`, `make check` (it needs the
[integration prerequisites](4.testing.md#before-a-pull-request)).

## Once on GitHub

1. Create `main` and `dev`, and protect them; use squash merges for pull requests. Allow
   release automation and the documented `main` → `dev` merge sync to push as needed.
2. Workflow permissions "Read and write", and GitHub Pages from `gh-pages`
   ([5. Release](5.release.md#repository-settings-once)).
3. Install the Renovate app on the repository.

## Stay in sync with upstream

Shared files: `makefiles/`, `Makefile`, `scripts/emoji_commit_parser.py`, `.pre-commit-config.yaml`,
`.markdownlint-cli2.yaml`, `.github/`, `docs/developer/`.

```bash
git remote add upstream https://github.com/AmineDjeghri/generative-ai-project-template.git
git fetch upstream
git checkout upstream/main -- makefiles/release.mk   # the files you want
git diff --staged                                     # review before committing
```
