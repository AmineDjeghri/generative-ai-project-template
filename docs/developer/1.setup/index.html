    1. Setup¶

    Install the workspace and run it with your chosen model provider.

    Prerequisites¶

    Make, Bash, Git and uv on Ubuntu 22.04+ or macOS. uv provisions Python 3.14.8 (>=3.14.8,<3.15); run make install-uv if uv is missing. Docker/Compose 2.24+ is optional; GPU Compose requires NVIDIA drivers.

    Install¶

    git clone https://github.com/AmineDjeghri/generative-ai-project-template.git
cd generative-ai-project-template
make install-dev
cp .env.example .env

    This installs backend, frontend and dev/docs tools, without PyTorch, and, in a Git checkout, the Git hooks. Configure INFERENCE_* and EMBEDDINGS_* in .env using your provider's LiteLLM model names.

    For full checks, configure the integration prerequisites, then run:

    make pre-commit   # static checks and hooks
make test-all     # tests, including real model requests
make docs-build   # strict documentation build

    make check runs all three at once (and first warns if the Git hooks are missing). Use make test-local for offline diagnostics.

    Run¶

    For a cloud provider, remote Ollama or an already managed model server:

    make run

    For local Ollama:

    make install-ollama
make run-with-ollama

    The local command starts/reuses Ollama and downloads missing models before starting the app. Keep OLLAMA_MODEL_NAME and OLLAMA_EMBEDDING_MODEL_NAME consistent with the .env deployment names.

    URL / command Use
    http://localhost:8080 Frontend
    http://localhost:8000/docs Backend API docs
    make run-backend / make run-frontend Start either side separately
    make run-frontend-backend Start both without provider preparation

    Docker¶

    make docker-compose

    Use make docker-compose-cuda for NVIDIA GPU access. After source changes, run make docker-compose-rebuild or make docker-compose-cuda-rebuild. For bundled Ollama, .env provider URLs must use http://ollama:11434; native execution uses http://localhost:11434. Preflight checks URLs and Docker access without rewriting them. Wait for model provisioning and backend readiness. Direct docker compose up bypasses preflight.

    Models persist in ollama-data; missing models are downloaded on first start. Container logs default to INFO; LOGGING_LEVEL=DEBUG enables reload.

    Timeouts and retries¶

    Override these values in .env or the environment, then restart the app. Keep the model timeout below the chat deadline and the frontend timeout above it. The chat deadline includes retries; HTTPX timeouts apply per network operation.

    Setting Default Controls
    INFERENCE_TIMEOUT_SECONDS 60 One model request
    INFERENCE_RETRY_WAIT_SECONDS 2 Delay between rate-limit attempts; zero allowed
    INFERENCE_MAX_ATTEMPTS 3 Total rate-limit attempts
    CHAT_TIMEOUT_SECONDS 90 Chat deadline, including retries
    BACKEND_REQUEST_TIMEOUT_SECONDS 120 Frontend HTTP read/write/pool timeout
    BACKEND_CONNECT_TIMEOUT_SECONDS 5 Frontend connection timeout

    Timeouts must be positive and attempts at least one. Compose forwards all six settings.

    Documentation site¶

    make deploy-doc-local

    Everyday commands¶

    Command Use
    make check The full local gate before a pull request
    make test-local Self-contained tests only
    make pre-commit Run the static hooks; FILES="path/a path/b" limits them to files
    make docs-build Strict documentation build
    make deploy-doc-local Preview the documentation site
    make clean Remove caches and temporary files
    make help List all targets

    Optional environments and tools¶

    Command Use
    make install-prod / make install-prod-cuda Production dependencies only
    make install-tools Quality and docs tools without the application dependencies
    make install-release Packaging and release tools without the application dependencies
    make update-uv Update an existing uv installation
    make act Run GitHub Actions locally (make install-act first; needs Docker and .env)
    make install-dev-cpu / make install-dev-cuda Optional Python PyTorch development; does not accelerate Ollama
    make install-backend / make install-backend-cuda Backend only
    make install-frontend Frontend only

    For publication, see release credentials.

    Editor and agent rules¶

    Select .venv/bin/python; mark backend/src, frontend/src and tests as source/test roots. Follow .editorconfig for formatting. Agent rules live in AGENTS.md; CLAUDE.md links to it for Claude Code. Edit AGENTS.md to update the shared instructions.

    make help lists all targets. Next: Conventions and Testing.
